# Getting help

- **Questions and how-tos**: open a [GitHub Discussion](https://github.com/Sudharsansm/Bitsopay/discussions) (or an issue labelled `question`).
- **Bugs and feature requests**: [issues](https://github.com/Sudharsansm/Bitsopay/issues).
- **Security**: never in public; see [SECURITY.md](SECURITY.md).
- **Docs**: start at the [README](README.md) and the [docs folder](docs/).
